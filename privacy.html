Privacy Policy

Last updated: 20 October 2026

Melon Shorts is a private tool used only by the owner of the Melon YouTube channel. It is not offered to the public.

What data the app accesses

With the channel owner's permission (Google OAuth), the app uses these YouTube scopes:

  • youtube.upload: to upload the owner's own videos to their channel.
  • youtube.readonly: to read the channel's name and basic statistics.
  • yt-analytics.readonly: to read view, like, retention and subscriber statistics for the owner's own videos.

How the data is used and stored

The data is used only to upload videos and to improve future videos. The OAuth refresh token is stored privately and is never shared, sold or published. No data from other users is collected.

Google API Services

The app's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. It also uses YouTube API Services; see the YouTube Terms of Service and the Google Privacy Policy.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions.
